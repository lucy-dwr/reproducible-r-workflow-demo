# outputs/

This directory stores derived analysis products generated by the `targets` pipeline.

Generate these files by running:

```r
targets::tar_make()
```

| File | Description |
|:-----|:------------|
| `penguins_clean.rds` | Cleaned penguin dataset (missing values removed) |
| `species_summary.csv` | Body mass summary statistics by species |
| `body_mass_plot.png` | Boxplot of body mass by species and island |
| `model_summary.rds` | Tidy linear model coefficient table |

These files are derived outputs and can be regenerated from the pipeline at any time.
In a production repository with large outputs, consider excluding them from version control
and storing them in a separate release or object storage location.
