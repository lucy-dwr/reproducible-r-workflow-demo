# data/

This project loads data directly from the `palmerpenguins` R package — no raw data files
are stored in this directory.

```r
palmerpenguins::penguins
```

The dataset contains size measurements for 344 penguins across three species
(*Adelie*, *Chinstrap*, *Gentoo*) on three islands in the Palmer Archipelago, Antarctica.

**Reference:**
Horst AM, Hill AP, Gorman KB (2020). *palmerpenguins: Palmer Archipelago (Antarctica) penguin data.*
R package version 0.1.0. <https://allisonhorst.github.io/palmerpenguins/>

**Original data:**
Gorman KB, Williams TD, Fraser WR (2014). Ecological sexual dimorphism and environmental
variability within a community of Antarctic penguins (genus *Pygoscelis*).
*PLOS ONE* 9(3): e90081. <https://doi.org/10.1371/journal.pone.0090081>
